## 4. 负向用例与边界

- 空链接：`](https://example.com)` 或 `]()` 必须失败。
- 空来源：`来源：，检索日期 2026-10-06` 必须失败。
- 日期格式：`检索日期 2026/10/06`、`检索日期` 后无值必须失败。
- 空日期列表：空文本经 `auditDates` 返回 `{ markers: 0, dates: 0, invalid: [] }`。
- 多日期片段：`检索日期 2026-10-06；检索日期 2025-06-01` 必须返回 markers=2、dates=2、invalid=[]。
- 格式错误片段：`检索日期 2026/10/06` 必须进入 invalid，且 dates 不计数。
- 裸写日期：`见检索日期。` 必须进入 invalid，避免用裸写「检索日期」凑标记数。
- 交通价格不一致：README 有 `40–80 泰铢` 而 docs 删掉时必须失败。
- 构造错日期：登记 `2026-10-06`、正文写 `2026-10-07` 时必须返回 1 条不一致，且同时带出两个日期。
- 构造缺日期：正文 URL 行没有日期时必须返回 1 条「正文 URL 行缺少日期」。
- 构造缺登记行：正文出现登记表没有的 URL 时必须返回 1 条「来源登记缺少日期」。
- 非法输入：`datesInLine(undefined)` 返回 `[]`、`registerDateFor('', url)` 返回 `null`，不得抛异常，也不得用空数组冒充通过。
- 住宿价位不一致：README `300–500` 与 docs `300-500` 写法不一致时需人工确认；测试目前按全角连字符 `–` 检查。

### 6.4 构造不一致数据的期望失败输出（示例，不是实际运行日志）

若把登记的 `2026-10-06` 与正文的 `2026-10-07` 对齐失败，`urlDateMismatches` 返回：

```text
['URL 日期与登记不一致：https://example.com/a 2026-10-07 != 2026-10-06']
```

对应断言失败时进程输出形如：

```text
FAIL 构造不一致数据时 URL 日期校验必须失败
AssertionError [ERR_ASSERTION]: 未捕获日期不一致
```

该示例用于说明失败信号长什么样，不能当作已运行证据；评审需自行运行并贴出真实输出。

### 6.5 误报面与白名单策略

- URL 正则为 `https?:\/\/[^\s)），,；;]+`，会在半角/全角括号与中英文标点处截断；当前正文 5 个 URL 均为纯 ASCII 且以 `.html` 结尾，截断后与登记表完全一致，故零误报。
- 一行出现多个 URL 时逐个比对，行内任一日期与任一所查 URL 的登记日期不符即报错；当前正文每行至多 1 个 URL。
- 同一 URL 在多行出现时逐行比对；当前正文每个 URL 只出现 1 行。
- 白名单策略：不设白名单。若未来需要引用不同检索日期，必须在 source-register 新增一行并写明新日期，而不是在测试里放行。
- 若 URL 因含括号被截断导致误报，处理方式是把链接改写为不含括号的规范写法，或在登记表按同一截断结果登记，并在 PR 说明；不得只放宽正则而不补用例。

### 6.6 解析健壮性与错误传播

- `datesInLine(line)`：`typeof line !== 'string'` 或空串返回 `[]`；正则 `20\d{2}-\d{2}-\d{2}` 只认连字符格式，`2026/10/06` 与裸写「检索日期」不计入合法日期。
- `registerDateFor(register, url)`：`register` 非字符串按空表处理；URL 缺行或缺日期返回 `null`。
- `urlDateMismatches`：自身不抛异常，把问题写成中文字符串数组返回；调用方用 `assert.deepStrictEqual(..., [])` 与 `length` 断言，因此缺日期、缺行不会被静默忽略，失败时测试进程 exitCode 置 1。
- `auditDates` 保持 `{ markers, dates, invalid }` 返回结构不变，既有断言「日期审计函数覆盖空态、多日期与非法格式」继续生效。
- 调用点：`auditDates` 仅被上述既有用例调用；`urlDateMismatches` 被新增两个用例调用；`datesInLine`/`registerDateFor` 仅被 `urlDateMismatches` 与健壮性用例调用。三者都在测试进程内，不进入文档渲染或生产路径，不影响 README 与 docs 正文。
