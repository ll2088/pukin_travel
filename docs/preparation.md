# 行前准备

## 行前准备

- [ ] 护照有效期不少于 6 个月，并准备回程机票行程单
- [ ] 出发前查询泰国官方最新签证与 ETA 要求（政策可能变化）
- [ ] 填写 TDAC 电子入境卡并保存确认页
- [ ] 购买旅游保险，保存电子保单
- [ ] 提前预订住宿与跳岛一日游，确认是否含酒店接送
- [ ] 准备防晒霜、泳衣、防水袋、常用药品、晕船药与转换插头
- [ ] 下载 Grab 或 Bolt，绑定可境外支付的银行卡
- [ ] 兑换少量泰铢现金，用于夜市、小费与街边摊
- [ ] 雨季出行准备室内备选活动，并出发前确认跳岛船班是否停驶

## 预订清单

- 住宿：确认早餐、机场接送与取消政策。
- 跳岛一日游：确认集合时间、含餐与取消退款规则。
- 保险：覆盖浮潜与摩托活动（如参加）。

## 来源与时效

- 清单参考公开攻略（检索日期 2026-01-01），来源为微信公众号攻略与家庭游安全经验。
- 政策与价格以官方渠道为准。
