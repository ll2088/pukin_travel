# 安全须知

## 安全

- 打车仅使用 Grab 或 Bolt 等正规 App，不接受陌生人包车或路边议价。
- 不偏离计划行程，夜间避免单独前往偏僻海滩。
- 出海听从船员安全指引，穿救生衣，雨季确认船班是否停驶。
- 饮食选择卫生条件较好的餐厅，饮用瓶装水。
- 保存旅游保险保单与紧急联系方式，遇紧急情况联系中国驻泰国使领馆。

## 紧急联系方式

- 泰国旅游警察：1155
- 急救：1669
- 中国驻泰国使领馆：出发前查询最新电话并保存。

## 来源与时效

- 安全原则参考公开攻略（检索日期 2026-01-01），来源为家庭游安全经验与微信公众号攻略。
- 紧急电话可能变化，出发前以官方公告为准。
