# pukin_travel

普吉岛 4 天 3 晚旅游计划（可执行版）。

## 行程概览

- 天数：4 天 3 晚
- 主线：跳岛 + 普吉镇老街 + 海滩放松 + 按摩购物
- 住宿建议：芭东（热闹、餐饮多）、卡塔/卡伦（安静、适合度假）、普吉镇（方便老街）
- 适合人群：首次到访、情侣或朋友小团

## 行前准备

- [ ] 护照有效期不少于 6 个月，并准备回程机票行程单
- [ ] 出发前查询泰国官方最新签证与 ETA 要求（政策可能变化）
- [ ] 购买旅游保险，保存电子保单
- [ ] 提前预订住宿与跳岛一日游，确认是否含酒店接送
- [ ] 准备防晒霜、泳衣、防水袋、常用药品与转换插头
- [ ] 下载 Grab 或 Bolt，绑定可境外支付的银行卡
- [ ] 兑换少量泰铢现金，用于夜市、小费与街边摊
- [ ] 雨季出行准备室内备选活动，并出发前确认跳岛船班是否停驶

## 住宿

- 芭东区域：餐饮、夜市与夜生活集中，适合喜欢热闹的游客；缺点是较吵。
- 卡塔/卡伦区域：海滩安静，适合度假与家庭；餐饮选择少于芭东。
- 普吉镇区域：方便逛老街与周末夜市，去海滩需乘车约 30–40 分钟。
- 预订提示：确认是否含早餐、是否提供机场接送，并查看近期住客评价。

## 交通

- 机场往返：可选机场包车或 Grab，价格透明，适合 2–4 人。
- 市内出行：优先使用 Grab 或 Bolt，按 App 计价，避免路边议价纠纷。
- 跳岛交通：预订含酒店接送的一日游船班，确认出发码头与集合时间。
- 摩托车租赁：仅建议有经验且持有效驾照的游客选择，务必佩戴头盔并确认保险。
- 普吉镇与海滩之间距离较远，单程通常需 30–40 分钟，行程安排需预留车程。

## 逐日行程

### 第 1 天：抵达与芭东海滩

- 上午：抵达普吉机场，办理入境后乘机场包车或 Grab 前往芭东酒店，车程约 45–60 分钟。
- 下午：入住后前往芭东海滩散步，适应时差，避免安排高强度活动。
- 晚间：芭东夜市晚餐，体验街边小吃；可做一次泰式按摩放松。

### 第 2 天：皮皮岛跳岛一日游

- 上午：酒店早餐后，按一日游集合时间在酒店大堂等候接送，前往码头乘船。
- 下午：皮皮岛浮潜与海滩停留，注意防晒与补水；听从船员安全指引。
- 晚间：返回芭东，晚餐后休息；雨季如船班停驶，改为普吉镇老街与室内活动。

### 第 3 天：普吉镇老街与文化体验

- 上午：从芭东乘 Grab 前往普吉镇，车程约 30–40 分钟，逛老街与彩色骑楼。
- 下午：参观当地庙宇与咖啡馆，品尝福建面等本地美食。
- 晚间：普吉镇周末夜市（如逢周末），之后乘 Grab 返回酒店。

### 第 4 天：海滩放松与返程

- 上午：酒店早餐后退房，寄存行李，前往卡塔或卡伦海滩放松。
- 下午：午餐后返回酒店取行李，按航班时间提前 3 小时前往机场。
- 晚间：办理登机手续返程；如航班较晚，可在机场附近用餐。

## 实用提示

- 旺季与雨季差异明显，雨季跳岛船班可能停驶，需预留备选方案。
- 签证、ETA 与免签政策可能变化，出发前以泰国官方最新规定为准。
- 本文信息来自公开攻略整理，价格与时效信息请以官方渠道和实际预订为准。

### 行程框架

原文亲子 4 日游主线为「Day 1 芭东 + Day 3 皇帝岛」，Day 2 与 Day 4 未完整覆盖，本仓库按以下框架补齐：

- Day 1：抵达普吉机场，入住芭东酒店，下午芭东海滩散步，晚间芭东夜市与泰式按摩。
- Day 2：皮皮岛跳岛一日游（含酒店接送），雨季停驶时改用普吉镇老街与室内活动（见 Day2 备选）。
- Day 3：皇帝岛一日游，浮潜与海滩停留，晚间返回芭东休息。
- Day 4：退房后卡塔或卡伦海滩放松，按航班时间提前 3 小时前往机场返程（见 Day4 备选）。

### 预订渠道

- 当地一日游：可通过淘宝当地旅行社店铺预订，确认是否含酒店接送、出发码头与集合时间。
- 酒店：可使用雅高达（Agoda）或携程比价预订，重点查看近期住客评价、是否含早餐与机场接送。
- 机票：建议在航空公司官网或主流 OTA 购买，并附加航班延误保险。
- 签证：出发前查询泰国官方最新签证与 ETA 要求；原文提及落地签费用约 1200 泰铢，该费用与材料要求可能已变化，需以官方渠道为准。

- 签证费用、机票价格、酒店推荐等时效性信息可能已变化，出发前需核实最新政策与报价。
- 游记未完整覆盖 Day 2 与 Day 4，直接套用可能导致计划不完整，需结合本仓库备选方案。

- 亲子出行需额外关注儿童防晒、补水、晕船与常用药品准备。

### Day2 备选

- 皮皮岛跳岛一日游（主选）：含酒店接送，注意儿童救生衣与浮潜安全。
- 普吉镇老街与室内活动（雨天备选）：逛彩色骑楼、咖啡馆与当地庙宇，车程约 30–40 分钟。
- 幻多奇主题乐园（夜间备选）：适合亲子家庭，需提前确认演出时间与接送安排。

### Day4 备选

- 卡塔或卡伦海滩放松（主选）：退房后寄存行李前往，午餐后返回取行李赴机场。
- 西蒙人妖秀或按摩购物（晚班机备选）：适合航班较晚的游客，需预留前往机场的车程。
- 机场附近用餐与休息（保守备选）：按航班时间提前 3 小时到达机场。

### 不同人群玩法

- 亲子：以芭东与皇帝岛为主线，控制每日车程，优先选择含酒店接送的一日游，备好儿童药品与防晒。
- 情侣：可增加卡塔/卡伦安静海滩与普吉镇咖啡馆，晚间选择按摩或夜市，跳岛可选皮皮岛。
- 老人：减少跳岛强度，以普吉镇老街、海滩散步与按摩为主，出行优先包车或 Grab，避免长时间乘船。
