# pukin_travel

普吉岛 4 天 3 晚旅游计划（可执行版）。

本文合并两套公开攻略的四日排法，供按航班时刻与体力二选一，也可交叉参考。

## 行程概览

- 天数：4 天 3 晚
- 主线：跳岛 + 普吉镇老街 + 海滩放松 + 按摩购物
- 住宿建议：芭东（热闹、餐饮多）、卡塔/卡伦（安静、适合度假）、普吉镇（方便老街）
- 适合人群：首次到访、情侣或朋友小团
- 入境与季节要点：中国护照免签停留 30 天为公开攻略说法（来源：中华旅游网《普吉岛旅游全攻略》，检索日期 2026-10-06，非官方公告），出发前以泰国官方公告为准；11 月–4 月旱季优先安排跳岛，5–10 月雨季需备室内替代方案。
- 季节对照与五个住宿区的取舍见 [docs/phuket-4d3n.md](docs/phuket-4d3n.md) 的「季节与住宿区决策」一节。
- 详细行程文档：[docs/phuket-4d3n.md](docs/phuket-4d3n.md)
- 两套排法：[行程A](#行程a地理片区动线) 按地理片区推进，适合想少走回头路的游客；[行程B](#行程b老城日落与海滩巡礼) 把老城与日落放在第一天，适合下午抵达或偏好文化的游客。
- 信息来源与日期：行程A 参考「普吉岛经典四日·芭东、皮皮岛与普吉镇怎么排」（jiqunsoft.com，检索日期 2026-10-06）；行程B 参考 Trip.com「神仙半岛」旅客实拍与景点指南（tw.trip.com，检索日期 2026-10-06）。两者均为普通攻略站与用户分享，权威性一般，价格、开放时间与签证信息以官方或预订平台为准。

## 行前准备

- [ ] 护照有效期不少于 6 个月，并准备回程机票行程单
- [ ] 出发前查询泰国官方最新签证与 ETA 要求（政策可能变化，检索日期 2026-10-06 的攻略未给出确定结论，需以官方公告为准）
- [ ] 核对免签停留期是否为 30 天（来源：中华旅游网攻略，检索日期 2026-10-06，非官方公告），并把回程机票与酒店订单电子版存在手机里备查
- [ ] 出发前 3 天内填写泰国 TDAC 电子入境卡并截图保存（官网与政策以泰国官方最新公告为准）
- [ ] 购买旅游保险，保存电子保单
- [ ] 提前预订住宿与跳岛一日游，确认是否含酒店接送
- [ ] 皮皮岛出海优先选择双体船，并提前一天以上预订（来源：行程A 攻略，2026-10-06）
- [ ] 准备防晒霜、泳衣、防水袋、驱蚊用品、常用药品与转换插头
- [ ] 下载 Grab 或 Bolt，绑定可境外支付的银行卡
- [ ] 兑换少量泰铢现金，用于夜市、小费与街边摊；多数街边摊不支持刷卡
- [ ] 雨季出行准备室内备选活动，并出发前确认跳岛船班是否停驶
- [ ] 普吉岛多山且易堵车，点对点通勤可能超过 40 分钟，行程不宜排满

## 住宿

按偏好选择区域，三晚建议固定一处，避免频繁搬酒店。

| 区域 | 适合人群 | 优点 | 缺点 | 参考价位（人民币/晚，中等酒店双人间） |
| --- | --- | --- | --- | --- |
| 芭东 | 夜生活、餐饮便利 | 夜市、餐厅、按摩集中 | 较吵，海滩人多 | 300–500 |
| 卡塔/卡伦 | 亲子、度假 | 海滩安静，适合放松 | 餐饮选择少于芭东 | 350–600 |
| 普吉镇 | 文化、老街 | 方便逛老街与周末夜市 | 去海滩需乘车约 30–40 分钟 | 250–450 |
| 邦涛/拉威 | 长住、度假村与海鲜 | 拉威海鲜市场、度假村密度高 | 离主要景点远，基本靠包车 | 400–700 |

- 预订提示：确认是否含早餐、是否提供机场接送，并查看近期住客评价。
- 住宿策略：前两晚住芭东便于夜市与跳岛集合，最后一晚换卡伦/卡塔看海；不想搬酒店就三晚连住一处，代价是每天多 20–40 分钟车程。
- 价位为公开攻略与常见报价的参考区间（检索日期 2026-10-06），旺季与节假日会上浮，以实际预订为准。

## 交通

- 机场往返：可选机场包车或 Grab，价格透明，适合 2–4 人；机场到芭东车程约 45–60 分钟。
- 市内出行：优先使用 Grab 或 Bolt，按 App 计价，避免路边议价纠纷。
- 跳岛交通：预订含酒店接送的一日游船班，确认出发码头与集合时间。
- 摩托车租赁：仅建议有经验且持有效驾照的游客选择，务必佩戴头盔并确认保险。
- 普吉镇与海滩之间距离较远，单程通常需 30–40 分钟；南部海角（神仙半岛）距芭东车程约 40 分钟以上，行程安排需预留车程。

## 逐日行程

两套排法共用同一预算与住宿建议，可按航班时刻与体力二选一，也可交叉参考。

### 行程A：地理片区动线

按机场、芭东、普吉镇、南部海角的地理位置推进，一天只动一到两个片区。

#### Day 1：抵达与芭东海滩

- 上午：抵达普吉机场，办理入境后乘机场包车或 Grab 前往芭东酒店，车程约 45–60 分钟。
- 下午：入住后前往芭东海滩散步，适应时差，避免安排高强度活动。
- 晚间：芭东夜市晚餐，体验街边小吃；可做一次泰式按摩放松。
- 餐饮：早餐自理，午餐机场或酒店附近，晚餐芭东夜市。
- 交通：机场包车或 Grab 至芭东。

#### Day 2：皮皮岛跳岛一日游

- 上午：酒店早餐后，按一日游集合时间在酒店大堂等候接送，前往码头乘船。
- 下午：皮皮岛浮潜与海滩停留，注意防晒与补水；听从船员安全指引。
- 晚间：返回芭东，晚餐后休息；雨季如船班停驶，改为普吉镇老街与室内活动。
- 餐饮：早餐酒店，午餐一日游含餐，晚餐芭东餐厅。
- 交通：一日游含酒店接送与船班。

#### Day 3：普吉镇老街与文化体验

- 上午：从芭东乘 Grab 前往普吉镇，车程约 30–40 分钟，逛老街与彩色骑楼。
- 下午：参观当地庙宇与咖啡馆，品尝福建面等本地美食。
- 晚间：普吉镇周末夜市（如逢周末），之后乘 Grab 返回酒店。
- 餐饮：早餐酒店，午餐老街本地餐厅，晚餐周末夜市或镇内餐厅。
- 交通：Grab 往返芭东与普吉镇。

#### Day 4：南部海角与返程

- 上午：酒店早餐后退房，寄存行李，前往卡塔或卡伦海滩放松。
- 下午：午餐后前往神仙半岛（Promthep Cape）观景，车程约 40 分钟以上；随后返回酒店取行李，按航班时间提前 3 小时前往机场。
- 晚间：办理登机手续返程；如航班较晚，可在机场附近用餐。
- 餐饮：早餐酒店，午餐卡塔/卡伦，晚餐机场或机上。
- 交通：Grab 或包车串联海滩、神仙半岛与机场。

### 行程B：老城日落与海滩巡礼

把老城与日落放在第一天，把海滩巡礼与夜生活放在第三天，适合下午抵达或偏好文化的游客。

#### Day 1：老城与日落

- 上午：抵达普吉机场，办理入境后乘机场包车或 Grab 前往酒店，车程约 45–60 分钟。
- 下午：入住后前往普吉镇老街，逛彩色骑楼与咖啡馆。
- 晚间：前往神仙半岛看日落，之后返回酒店附近晚餐。
- 餐饮：早餐自理，午餐机场或酒店附近，晚餐老城或酒店附近餐厅。
- 交通：机场包车或 Grab，镇内 Grab。

#### Day 2：皮皮岛跳岛一日游

- 上午：酒店早餐后，按一日游集合时间在酒店大堂等候接送，前往码头乘船。
- 下午：皮皮岛浮潜与海滩停留，注意防晒与补水；听从船员安全指引。
- 晚间：返回酒店，晚餐后休息；雨季如船班停驶，改为老城室内活动。
- 餐饮：早餐酒店，午餐一日游含餐，晚餐酒店附近餐厅。
- 交通：一日游含酒店接送与船班。

#### Day 3：海滩巡礼与夜生活

- 上午：酒店早餐后前往卡塔或卡伦海滩，游泳与放松。
- 下午：海滩午餐后返回芭东，逛芭东海滩与周边商店。
- 晚间：芭东夜市晚餐，体验夜生活；可做泰式按摩。
- 餐饮：早餐酒店，午餐海滩餐厅，晚餐芭东夜市。
- 交通：Grab 串联酒店、卡塔/卡伦与芭东。

#### Day 4：购物与返程

- 上午：酒店早餐后退房，寄存行李，前往附近商场或市场购物。
- 下午：午餐后返回酒店取行李，按航班时间提前 3 小时前往机场。
- 晚间：办理登机手续返程；如航班较晚，可在机场附近用餐。
- 餐饮：早餐酒店，午餐商场或市场，晚餐机场或机上。
- 交通：Grab 或包车至机场。

## 实用提示

- 旺季与雨季差异明显，雨季跳岛船班可能停驶，需预留备选方案。
- 签证、ETA 与免签政策可能变化，出发前以泰国官方最新规定为准。
- 本文信息来自公开攻略整理（检索日期 2026-10-06），价格与时效信息请以官方渠道和实际预订为准。
- 两套行程的第一天和第三天安排不同，需按航班时刻和体力取舍。
- 普吉岛多山且堵车，点对点通勤可能超过 40 分钟，行程不宜排得过满。
- 寺庙礼仪：查龙寺与大佛需遮肩遮膝、脱鞋入殿，出发前在包里放一件薄外套或围巾。
- 免签、船班与景点开放时间均可能变动；本文引用的攻略日期为 2026-10-06，预订与出发前请再核对一次官方渠道。
